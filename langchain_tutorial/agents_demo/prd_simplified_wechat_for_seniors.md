# 项目背景
随着智能手机的普及，越来越多的老年人开始使用手机进行社交、支付和娱乐等日常活动。然而，复杂的操作界面和繁琐的功能设置常常让他们感到困扰。因此，开发一款针对老年人的极简版微信，专注于打电话和发送照片功能，将有助于提升他们的使用体验，满足他们的基本通信需求。

# 用户画像
- **年龄**：60岁及以上  
- **技术水平**：对智能手机的使用较为陌生，习惯于传统的通信方式  
- **需求**：希望能够方便地与家人和朋友保持联系，主要通过电话和照片分享  
- **痛点**：现有的社交应用功能复杂，操作不便，容易造成使用障碍

# 核心功能列表 (MVP)
1. **一键拨号**：用户可以通过简单的界面快速拨打常用联系人电话。  
2. **照片发送**：允许用户选择照片并发送给联系人，操作简单直观。  
3. **语音提示**：在操作过程中提供语音提示，帮助用户理解每一步的操作。  
4. **大字体和高对比度界面**：界面设计采用大字体和高对比度色彩，方便老年人阅读。  
5. **简化的联系人管理**：用户可以轻松添加、删除和管理联系人。

# 技术风险
- **用户接受度**：老年用户对新应用的接受度可能较低，需要进行充分的用户测试和反馈收集。  
- **设备兼容性**：需要确保应用在不同品牌和型号的手机上都能流畅运行。  
- **安全性**：在设计过程中需考虑用户的隐私和数据安全，防止信息泄露.

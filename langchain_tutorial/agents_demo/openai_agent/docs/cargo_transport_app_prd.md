# 货车拉货小程序 PRD

## 项目背景与目标
开发一个专门用于叫货车拉货的小程序，主要服务于搬家的年轻人和有拉货需求的小商户，提供便捷的货车叫车服务。

## 用户角色 (User Roles)
1. **用户**：  
   - 年轻人（搬家需求）  
   - 小商户（拉货需求）  
2. **司机**：  
   - 自带面包车或小货车的个体司机

## 核心功能模块 (Functional Requirements)
1. **地图定位**：  
   - 用户可以通过地图选择上车地点和目的地。  
2. **按里程计费**：  
   - 根据用户选择的起点和终点，系统自动计算费用。  
3. **预约用车**：  
   - 用户可以选择立即用车或预约未来的用车时间。  
4. **线下结算**：  
   - 用户与司机在服务完成后进行线下结算，无需在线支付。

## 技术约束与非功能需求
- **技术约束**：  
  - 需要集成地图服务（如高德地图或百度地图）。  
  - 需要实现实时定位和路线规划功能。  
- **非功能需求**：  
  - 用户界面友好，易于操作。  
  - 系统响应时间快，确保用户体验流畅。

使用帮助

1. 连接数据库

点击右上角设置按钮，填写数据库连接信息。支持MySQL和PostgreSQL。

2. 浏览表结构

连接成功后，左侧将显示所有表。点击表名查看详细结构。

3. 生成SQL查询

在输入框中描述您的查询需求，助手会自动生成相应的SQL语句。

4. 执行查询

确认SQL语句无误后，点击执行按钮运行查询并查看结果。

5. 结果可视化

查询结果将在右侧显示，并根据数据类型提供可视化图表。
